One-time setup, about 2 minutes. Needs Spotify Premium.

  1. Open developer.spotify.com/dashboard and choose Create app.
  2. Any name and description. Under Redirect URIs add exactly:
  3. Tick Web API and Web Playback SDK, save, then copy the Client ID.

Tip: paste the Client ID into the CLIENT_ID line at the top of the script in index.html, and this screen becomes a single “Log in” button for everyone.

Friends must be added under the Spotify app’s User Management (max 5 people).
